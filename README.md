# Resting-State Functional Connectivity and Social Motivation in Autism

## Project Overview

This project investigates the relationship between resting-state functional connectivity and individual differences in social motivation among children and adolescents with autism spectrum disorder (ASD).

## Research Question

Does functional connectivity between the nucleus accumbens (NAc) and anterior cingulate cortex (ACC), and between the insula and ACC, predict social motivation scores in children and adolescents with ASD?

## Dataset

- Dataset: Autism Brain Imaging Data Exchange II (ABIDE II)
- Modality: Resting-state functional MRI
- Population: Children and adolescents with ASD
- Imaging sites: GU, KKI, OHSU, SDSU, UCD
- Available imaging participants: 171
- Preprocessing: DCAN derivatives
- Atlas: HCP2016 FreeSurfer Subcortical (379 parcels)

## Planned Analysis

1. Dataset validation and organization
2. Motion quality control
3. Anatomical ROI definition
4. ROI-to-ROI functional connectivity extraction
5. Statistical regression analysis
6. Results visualization and interpretation

## Primary Outcome

SRS Social Motivation T-score.

## Predictors

- NAc–ACC functional connectivity
- Insula–ACC functional connectivity

## Covariates

- Age
- Sex
- Head motion
- Imaging site

## Project Status

Dataset validation completed. Motion quality control and analysis criteria are under review. Functional connectivity analysis has not yet begun.

## Reproducibility

Analysis scripts, methodological decisions, and software requirements will be documented in this repository.

Raw neuroimaging data and participant-level phenotypic data are not included.

## Data Availability

ABIDE II is a publicly available neuroimaging dataset distributed through the Autism Brain Imaging Data Exchange.
